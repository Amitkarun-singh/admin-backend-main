# AI Features Database Documentation

This document describes the database tables utilized by the AI-powered features in the `src/ai-features` directory, including Gini Chatbot, AI Practice Questions, and Student Performance Analytics.

## 1. System & Logging Tables

### `logs`
Used by the logging middleware to track AI-related API interactions for auditing and debugging.
*   **Columns:**
    *   `conversation_id`: Unique UUID for the request/session.
    *   `method`: HTTP method (POST, GET, etc.).
    *   `url`: The endpoint accessed.
    *   `status_code`: HTTP response status.
    *   `device`: User-agent string identifying the client.
    *   `request_body`: JSON string of the incoming request.
    *   `response_body`: JSON string of the outgoing response.
    *   `user_details`: JSON string containing student/user metadata.
    *   `created_at`: Timestamp of the log entry.

## 2. Gini Chatbot Tables

### `Chat_feedback`
Stores user sentiment and feedback regarding AI chatbot responses.
*   **Columns:**
    *   `userMessage`: The prompt sent by the student.
    *   `botResponse`: The AI's generated response.
    *   `feedback`: User feedback (e.g., 'LIKE', or specific text for 'DISLIKE').

## 3. Practice Questions Module

### `practice_tests`
Records metadata for every AI-generated test session.
*   **Columns:**
    *   `id`: Primary Key (Auto-increment).
    *   `student_id`: Reference to the student who initiated the test.
    *   `class`: Targeted grade/class level.
    *   `subject`: Subject of the test.
    *   `chapter`: Specific chapter or topic.
    *   `language`: Language of the generated content.

### `practice_questions`
Stores individual questions generated by the AI for a specific test.
*   **Columns:**
    *   `test_id`: Foreign Key linking to `practice_tests`.
    *   `question_id`: UUID generated by the AI to track unique questions.
    *   `type`: Question type (MCQ, SA - Short Answer, LA - Long Answer).
    *   `question`: The text of the question.
    *   `options`: JSON array of choices (only for MCQ).
    *   `answer`: The correct answer/marking scheme.
    *   `student_answer`: The answer submitted by the student.
    *   `answer_explanation`: Detailed explanation provided by the AI.

## 4. Student Performance & Analytics

### `test_attempts`
Tracks the scores and timestamps of completed tests.
*   **Columns:**
    *   `student_id`: Reference to the student.
    *   `test_id`: Reference to the core `tests` table.
    *   `score`: The numeric score achieved.
    *   `attempted_at`: Timestamp of the attempt.

### `study_time`
Logs the duration students spend engaging with the platform.
*   **Columns:**
    *   `student_id`: Reference to the student.
    *   `minutes_spent`: Total duration in minutes.
    *   `study_date`: The date of the study session.

### `monthly_progress`
Aggregated data used for generating monthly growth charts.
*   **Columns:**
    *   `student_id`: Reference to the student.
    *   `subject_id`: Reference to the `subjects` table.
    *   `month`: The month name or date.
    *   `score_percentage`: Average score for that month/subject.

## 5. Core Master Tables (Shared)
The AI features also interact with the following system-wide tables for joins and statistics:
*   **`subjects`**: Contains subject names and IDs.
*   **`tests`**: Contains master test definitions.
*   **`questions`**: Core question bank used for global counts and stats.
